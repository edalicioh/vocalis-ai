# Requirements: Milestone v1.2 — Histórico, Busca, IA & Redesign UX/UI

> Definição dos requisitos escopados para o marco v1.2 do Copiloto de Conversas.

## Requirements

### Histórico & Busca (HIST)

- [x] **HIST-01**: Armazenar o histórico de reuniões passadas com transcrições e atas no banco local da extensão.
- [x] **HIST-02**: Permitir busca por palavra-chave e filtragem rápida das reuniões salvas na extensão.

### Provedores de IA (AI)

- [x] **AI-04**: Suporte aos provedores de nuvem OpenAI (GPT-4o) e Anthropic (Claude 3.5) via interface `AnswerProvider`.
- [x] **AI-05**: Suporte a modelos de IA 100% locais rodando via Ollama (Llama 3 / Mistral) para garantir total privacidade.

### Arquitetura Visual & UI/UX (UI)

- [x] **UI-01**: Decompor o overlay monolítico em 4 widgets flutuantes independentes (Barra de Funções, Painel de Resposta, Painel de Transcrição, Indicador de Status).
- [x] **UI-02**: Implementar controle de arraste (`drag-to-move`), minimização/ocultação e persistência de posições e estados de cada widget em `localStorage`.
- [x] **UI-03**: Aplicar o Design System `MASTER.md` (dark mode OLED, backdrop blur, fonte Inter, substituição de emojis por ícones Lucide SVG).
- [x] **UI-04**: Implementar destaque visual de sentença lida por TTS e modos de layout rápido (Padrão, Compacto, Leitura, Palavras-chave).
