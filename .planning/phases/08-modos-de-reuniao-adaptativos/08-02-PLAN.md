# Plan 08-02: Prompts de Sistema Adaptativos no Orquestrador

## Objectives
Implementar o suporte a System Prompts especializados por modo (`technical_interview`, `system_design`, `code_review`, `general`) no Orquestrador e gerenciar a troca dinâmica em tempo real via WebSocket `settings.update`.

## Tasks

<task id="08-02-01" type="code">
  <name>Implementar dicionário de System Prompts e injeção de notas no ContextManager</name>
  <read_first>
    - apps/orchestrator/src/services/context-manager.ts
    - packages/shared-types/src/messages.ts
    - .planning/phases/08-modos-de-reuniao-adaptativos/08-CONTEXT.md
  </read_first>
  <action>
    Em apps/orchestrator/src/services/context-manager.ts:
    1. Criar o dicionário de SYSTEM_PROMPTS para cada MeetingMode:
       - technical_interview: Respostas diretas e concisas de até 30s para contratação.
       - system_design: Foco em requisitos funcionais/não-funcionais, trade-offs, escalabilidade e suporte a diagramas Mermaid.
       - code_review: Foco em qualidade de código, refatoração, análise de complexidade O(N) e segurança.
       - general: Síntese de alinhamentos, decisões tomadas e Action Items.
    2. Adicionar método setMeetingMode(mode: MeetingMode, modeNotes?: string) na classe ContextManager.
    3. Atualizar a montagem do prompt final para incluir o System Prompt do modo ativo e o bloco de notas customizadas do modo (se fornecido pelo usuário).
  </action>
  <acceptance_criteria>
    - apps/orchestrator/src/services/context-manager.ts contém a lógica de SYSTEM_PROMPTS por modo
    - O prompt do LLM injeta as diretrizes do modo ativo e as notas de apoio do usuário
  </acceptance_criteria>
</task>
