# Plan 09-02: RMS Energy Gate no AudioWorklet & Offscreen Document

## Objectives
Implementar a medição de energia RMS em JS no AudioWorklet `pcm-worklet.js`, filtrando o envio de pacotes de áudio silenciosos via WebSocket e transmitindo o estado VAD à extensão.

## Tasks

<task id="09-02-01" type="code">
  <name>Implementar filtro RMS e descarte de silêncio no pcm-worklet.js</name>
  <read_first>
    - apps/chrome-extension/public/pcm-worklet.js
    - .planning/phases/09-pipeline-de-audio-e-vad/09-CONTEXT.md
  </read_first>
  <action>
    Em apps/chrome-extension/public/pcm-worklet.js:
    1. Adicionar variável rmsThreshold (padrão: 0.01).
    2. No método process(inputs, outputs, parameters):
       - Calcular a energia RMS do buffer de 4096 amostras PCM: Math.sqrt(sum / count).
       - Se RMS >= rmsThreshold:
         - Transmitir o buffer PCM via port.postMessage(pcmBuffer).
         - Emitir port.postMessage({ type: 'VAD_STATE', isAudioActive: true, rms }).
       - Se RMS < rmsThreshold:
         - NÃO enviar o buffer PCM (economizando CPU e tráfego de rede).
         - Emitir port.postMessage({ type: 'VAD_STATE', isAudioActive: false, rms }).
    3. Adicionar escuta de port.onmessage para receber atualização dinâmica de rmsThreshold.
  </action>
  <acceptance_criteria>
    - pcm-worklet.js calcula o valor RMS de cada buffer PCM
    - Buffers com RMS abaixo de rmsThreshold são descartados localmente
    - O Worklet emite mensagens com o estado VAD (isAudioActive)
  </acceptance_criteria>
</task>
