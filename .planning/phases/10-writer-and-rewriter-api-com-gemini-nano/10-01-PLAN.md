# Plan 10-01: Módulo ChromeRewriterProcessor com Estratégia Híbrida

## Objectives
Criar o processador de reescrita local `ChromeRewriterProcessor` integrando a Rewriter/Writer API e a Prompt API local no Gemini Nano como fallback gracioso.

## Tasks

<task id="10-01-01" type="code">
  <name>Criar a classe ChromeRewriterProcessor</name>
  <read_first>
    - apps/chrome-extension/src/offscreen/chrome-ai-processor.ts
    - .planning/phases/10-writer-and-rewriter-api-com-gemini-nano/10-CONTEXT.md
  </read_first>
  <action>
    Criar apps/chrome-extension/src/offscreen/chrome-rewriter-processor.ts:
    1. Tipo RewriteStyle = 'shorten' | 'formal' | 'technical' | 'expand'.
    2. Método rewriteText(text: string, style: RewriteStyle): Promise<string>:
       - Tenta usar (window as any).ai?.rewriter / ai.writer.
       - Se indisponível ou lançar erro, faz fallback para (window as any).ai?.languageModel.create().
       - Prompts de fallback:
         - 'shorten': "Reescreva a resposta a seguir para ser extremamente curta e direta (máximo 20 palavras):"
         - 'formal': "Reescreva a resposta a seguir em tom altamente profissional e formal:"
         - 'technical': "Reescreva a resposta a seguir destacando termos técnicos, arquitetura e boas práticas:"
         - 'expand': "Reescreva a resposta a seguir adicionando mais detalhes explicativos e contexto:"
  </action>
  <acceptance_criteria>
    - O arquivo apps/chrome-extension/src/offscreen/chrome-rewriter-processor.ts é criado
    - O método rewriteText trata fallback para a Prompt API com sucesso
  </acceptance_criteria>
</task>
