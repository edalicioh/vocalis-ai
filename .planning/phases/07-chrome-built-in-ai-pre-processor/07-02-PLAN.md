# Plan 07-02: Módulo `ChromeBuiltInAIProcessor` no Offscreen Document

## Objectives
Implementar a classe `ChromeBuiltInAIProcessor` para execução no documento Offscreen da extensão Chrome, realizando a verificação do `window.ai`, correção ortográfica passiva e silenciosa de termos técnicos e a sumarização incremental híbrida (5 frases ou 60s) com fallback limpo.

## Tasks

<task id="07-02-01" type="code">
  <name>Criar módulo ChromeBuiltInAIProcessor em offscreen</name>
  <read_first>
    - apps/chrome-extension/src/offscreen/offscreen.ts
    - packages/shared-types/src/messages.ts
    - .planning/phases/07-chrome-built-in-ai-pre-processor/07-CONTEXT.md
  </read_first>
  <action>
    Criar o arquivo apps/chrome-extension/src/offscreen/chrome-ai-processor.ts com a classe ChromeBuiltInAIProcessor:
    1. Implementar método checkAvailability(): Promise<{ available: boolean; status: string }>.
       - Verifica typeof window !== 'undefined' && 'ai' in window && 'languageModel' in (window as any).ai.
       - Chama (window as any).ai.languageModel.capabilities() e retorna true apenas se status for 'readily' ou 'after-download'.
    2. Implementar método correctUtterance(text: string): Promise<{ text: string; corrected: boolean }>.
       - Se available for false (Bypass), retorna { text, corrected: false }.
       - Se disponível, cria sessão com prompt de poucas amostras (few-shot) focado em ajustar pontuação e jargões (ex: "Larabel" -> "Laravel", "Dockerizar" -> "Dockerize", "Fast-ify" -> "Fastify", "Vites" -> "Vitest", "Redis cluster" -> "Redis Cluster").
       - Em caso de falha runtime, faz fallback automático capturado em try/catch retornando { text, corrected: false }.
    3. Implementar o gerenciador de sumarização incremental updateSummary(newUtterance: string): Promise<{ summary?: string; shouldEmit: boolean }>.
       - Mantém contador de frases e timestamp da última sumarização.
       - Dispara sumarização quando frases >= 5 OU tempo decorrido >= 60.000ms.
       - Executa prompt enxuto para resumir tópicos chave em até 2 linhas e classificar categoria (DevOps, Backend, System Design, General).
  </action>
  <acceptance_criteria>
    - O arquivo apps/chrome-extension/src/offscreen/chrome-ai-processor.ts é criado
    - A classe ChromeBuiltInAIProcessor implementa checkAvailability, correctUtterance e updateSummary
    - Fallback gracioso ativo sem lançar exceções não tratadas quando window.ai não existe
  </acceptance_criteria>
</task>
